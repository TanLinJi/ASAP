## 1. Purpose / hypothesis

Install the OpenPCDet detector backend into the `asap` env (`E0.2`) and generate the four canonical KITTI info files plus `gt_database/`. These artifacts are the precondition for every detection-time experiment (`E1.x`, `E4.x`, `E5.x`).

Success criterion: `pcdet` imports cleanly inside `asap` env; `kitti_infos_train.pkl`, `kitti_infos_val.pkl`, `kitti_infos_trainval.pkl`, `kitti_infos_test.pkl` and `kitti_dbinfos_train.pkl` all exist with non-zero size, and `gt_database/` contains ≥ 19000 `.bin` clips.

## 2. Dependencies

- `E0.1` (KITTI data on disk at the canonical path).
- `E0.2` (the `asap` conda env).
- Outbound HTTP for any pip dependency that is not already cached.

## 3. Setup

### 3.1 Hardware & environment

- `asap` conda env from `E0.2`.
- `LD_LIBRARY_PATH=/root/miniconda3/envs/asap/lib/python3.9/site-packages/torch/lib:/usr/local/cuda-12.4/lib64` (set inside the helper scripts).

### 3.2 Code layout

OpenPCDet is **vendored** under `third_party/OpenPCDet/`, with its inner `.git` removed and a `third_party/README.md` recording the upstream commit and license. The local patch in `pcdet/datasets/__init__.py` makes the `Argo2Dataset` import optional so that KITTI-only environments do not require the `av2` dependency.

### 3.3 Symlinks

```text
/root/autodl-tmp/ASAP/third_party/OpenPCDet/data/kitti
  -> /root/autodl-tmp/ASAP/data/kitti
```

### 3.4 Reproducible command

```bash
cd /root/autodl-tmp/ASAP

# (a) Build symlink and verify layout
bash scripts/setup_openpcdet_backend.sh

# (b) Install pcdet editable into the asap env (CUDA build, no isolation)
conda run -n asap env \
    LD_LIBRARY_PATH=/root/miniconda3/envs/asap/lib/python3.9/site-packages/torch/lib:/usr/local/cuda-12.4/lib64 \
    python -m pip install --no-build-isolation -e third_party/OpenPCDet

# (c) Generate KITTI infos and gt_database
bash scripts/generate_kitti_infos.sh
```

## 4. Procedure

1. Run `setup_openpcdet_backend.sh` to create the `third_party/OpenPCDet/data/kitti` symlink and validate that `pcdet` source tree is intact.
2. Install `pcdet` editable with `--no-build-isolation` so that the local CUDA toolchain is used to compile the custom ops; `LD_LIBRARY_PATH` exports inside the script ensure `libc10.so` is found at link time.
3. Apply the local patch in `pcdet/datasets/__init__.py` so that the `Argo2Dataset` import is wrapped in `try/except`, allowing KITTI-only environments to skip the `av2` dependency.
4. Run `generate_kitti_infos.sh`, which calls `python -m pcdet.datasets.kitti.kitti_dataset create_kitti_infos tools/cfgs/dataset_configs/kitti_dataset.yaml` and produces all five pkl files plus `gt_database/`.

## 5. Expected output

- `kitti_infos_train.pkl` — 3712 entries.
- `kitti_infos_val.pkl` — 3769 entries.
- `kitti_infos_trainval.pkl` — 7481 entries.
- `kitti_infos_test.pkl` — 7518 entries.
- `kitti_dbinfos_train.pkl` — ground-truth database index.
- `gt_database/` — one `.bin` per ground-truth box (≈ 19700 files for KITTI Car/Ped/Cyc classes).
- Total size of pkl + database: ~200 MB.

## 7. Analysis

All info files generated and sized as expected; the gt_database file count matches the canonical KITTI Car/Ped/Cyc box count published by prior OpenPCDet users. The vendored OpenPCDet + local patch combination keeps the backend self-contained inside the ASAP repository, which simplifies reproducibility (no separate clone step for downstream users).

## 8. Issues encountered & resolutions

- **`pip install` failing on missing build isolation.** Fix: install with `--no-build-isolation` so that the host CUDA toolchain is used (recorded in `scripts/generate_kitti_infos.sh`).
- **Argo2Dataset import error.** Fix: local patch to `pcdet/datasets/__init__.py` makes the import optional. The patch is documented in `third_party/README.md` so it is not lost in a future upstream merge.
- **`libc10.so` not found at runtime.** Fix: set `LD_LIBRARY_PATH` before running any `pcdet` command; the helper scripts already export it.
