## 1. Purpose / hypothesis

Produce a detector-agnostic *geometric point-perturbation* attacked KITTI val set by randomly shifting LiDAR points inside annotated objects within a bounded per-axis displacement. This produces the attacked set consumed by `E3.*` and `E4.1`.

Important scope note: the current implementation is **not** PGD or detector-loss optimized. It is a bounded random geometric perturbation variant.

Success criterion: ≥ 10 absolute AP drop on KITTI Car/Moderate under no defense.

## 2. Dependencies

- `E1.1` clean PointPillars baseline.
- `E0.1` KITTI val data and `E0.3` OpenPCDet info files.

## 4. Procedure

1. Run the geometric perturbation script on all KITTI val frames.
2. Evaluate the no-defense PointPillars detector on the attacked set.
3. Persist AP and ASR to §6.
4. Feed the attacked set into SOR/ROR and ASAP for `E4.1`.

## 5. Expected output

- Attacked LiDAR bins and metadata.
- No-defense AP / ASR per detector for the `E4.x` *Perturbation* row.

## 7. Analysis

This is currently the strongest of the three KITTI PointPillars attacks in terms of Car AP drop and mAP drop. On nuScenes/VoxelNeXt, the original keyframe-only `epsilon=0.3` perturbation budget is milder than Injection: mAP drops from 60.52 to 51.87 and NDS from 66.64 to 59.95. The budget gate shows that `epsilon=0.5` is much stronger: mAP drops to 40.27 and NDS to 51.46, mAP ASR 33.5%. Use `epsilon=0.5` as the accepted nuScenes Perturbation budget for detector-transfer no-defense evaluation.

## 8. Issues encountered & resolutions

- The original E2.2 skeleton described a PGD-style perturbation attack. The implemented protocol is random bounded geometric perturbation; this distinction must remain visible in the paper.

## 9. Next actions

- Feed KITTI `epsilon=0.3` attacked val sets into the KITTI *Perturbation* row.
- Feed nuScenes `epsilon=0.5` attacked val sets into the accepted nuScenes *Perturbation* gate rows.
- If the final paper needs a stronger adaptive threat model, implement PGD-style detector-aware perturbation and rerun downstream defenses.
