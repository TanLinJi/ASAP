## 1. Purpose / hypothesis

Produce a detector-agnostic point-dropping attacked KITTI val set by randomly removing a fixed fraction of LiDAR points inside annotated objects.

Important scope note: the current implementation is **not** a detector-saliency dropping attack. It is a random object-point dropping variant.

Success criterion: ≥ 10 absolute AP drop on KITTI Car/Moderate.

## 2. Dependencies

- `E1.1` clean PointPillars baseline.
- `E0.1` KITTI val data and `E0.3` OpenPCDet info files.

## 4. Procedure

1. Run the random object-point dropping script on all KITTI val frames.
2. Evaluate the no-defense PointPillars detector on the attacked set.
3. Persist AP and ASR to §6.
4. Feed the attacked set into SOR/ROR and ASAP for `E4.1`.

## 5. Expected output

- Attacked LiDAR bins and metadata.
- No-defense AP / ASR per detector for the `E4.x` *Dropping* row.

## 7. Analysis

Dropping is the weakest of the three current KITTI PointPillars attacks on Car/Moderate AP, but it still produces a clear mAP drop because sparse classes degrade more strongly. Since the attack removes evidence, deletion-heavy defenses are expected to compound damage; E4.1 confirms this.

On nuScenes/VoxelNeXt, the keyframe-only `drop_ratio=0.5` budget is too weak: mAP ASR is only 2.7%. The upper-bound keyframe-only `drop_ratio=1.0` budget is still weak, with mAP ASR only 8.2%. This strongly suggests the limiting factor is OpenPCDet's clean historical sweeps (`MAX_SWEEPS=10`), not merely the drop ratio in the current keyframe. Do not use current keyframe-only Dropping as a strong nuScenes attack. Replace it with a sweep-aware or saliency-aware variant, or frame it only as a weak diagnostic.

## 8. Issues encountered & resolutions

- The original E2.3 skeleton described a saliency/gradient dropping attack. The implemented protocol is random object-point dropping; this distinction must remain visible in the paper.

## 9. Next actions

- Keep the KITTI Dropping row as-is.
- For nuScenes, keep Dropping paused for main claims; the `drop_ratio=1.0` budget gate failed to reach meaningful attack strength.
- If the final paper needs a stronger adaptive threat model, implement sweep-aware or saliency-based dropping and rerun downstream defenses.
