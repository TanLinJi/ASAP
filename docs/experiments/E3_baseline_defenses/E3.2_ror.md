## 1. Purpose / hypothesis

Apply *Radius Outlier Removal* (ROR) — a second classical denoising baseline — to the attacked val sets. ROR removes any point that has fewer than `min_neighbors` neighbors inside a fixed radius `r`, providing a non-statistical counterpart to `E3.1`.

## 2. Dependencies

- `E1.x` (clean), `E2.x` (attacked set).

## 3. Setup

### 3.1 Defense parameters

- Radius: `r_ror` (default: 0.3 m).
- Minimum neighbors: `min_neighbors` (default: 4).

### 3.2 Output layout

```text
outputs/defenses/kitti/E3.2_ror/
├── E2.1_injection/velodyne_defended/
├── E2.2_perturbation/velodyne_defended/
└── E2.3_dropping/velodyne_defended/
```

### 3.3 Reproducible command

```bash
PYTHONPATH=src /root/miniconda3/envs/asap/bin/python -m asap.defenses.statistical_filters \
    --method ror \
    --input_dir outputs/attacks/kitti/E2.1_injection/velodyne_attacked \
    --out_dir outputs/defenses/kitti/E3.2_ror/E2.1_injection/velodyne_defended \
    --radius 0.4 --min_neighbors 5
```

## 4. Procedure

1. Run `src/asap/defenses/statistical_filters.py --method ror` on every KITTI/PointPillars attacked val set.
2. Save defended bins under `velodyne_defended/`.
3. Evaluate the victim detector on the purified set.
4. Record AP / ASR.

## 5. Expected output

- Purified LiDAR bins and per-cell metrics.

## 6. Actual results

Clean reference (`E1.1`): PointPillars KITTI Car/Moderate 3D AP_R40 = 78.40; mAP_R40 Mod = 64.21.

| Attack | Car/Mod 3D AP_R40 | ASR vs clean Car | mAP_R40 Mod |
|--------|------------------:|-----------------:|------------:|
| E2.1 Injection | 66.07 | 15.7% | 51.30 |
| E2.2 Perturbation | 41.65 | 46.9% | 19.46 |
| E2.3 Dropping | 49.91 | 36.3% | 34.20 |

Raw summary source: `outputs/asap_vpsde/kitti_pointpillars_eval_summary.json`, entries `E2.1 ROR`, `E2.2 ROR`, `E2.3 ROR`.

## 7. Analysis

ROR is the strongest current baseline for injection because the attack inserts sparse off-surface points that a radius-neighbor criterion removes well. It is destructive for perturbation and dropping, where many legitimate object points also look sparse after the attack.
