## 1. Purpose / hypothesis

Run the ASAP pipeline with the **M2 anomaly gating disabled**, i.e. apply the M3 selective-diffusion step to every SPU regardless of score. Comparing this baseline against full ASAP isolates the contribution of anomaly-guided selection.

This file now tracks two fixed/all-unit diffusion proxies:

- `r=0.40`: completed SPD-style internal proxy used in the main ablation table.
- `r=0.15`: completed LiDAR-SPD-style radius proxy, because LiDAR-SPD reports `r1=0.15m, r2=0.10m`.

Neither row is an official LiDAR-SPD reproduction: LiDAR-SPD also includes spherical projection and a conditioned diffusion model. These proxies provide same-attack, same-detector stress tests for fixed spherical all-unit diffusion under our pipeline.

## 2. Dependencies

- `E1.x` clean baselines and `E2.x` attacked sets.
- ASAP M1 + M3 implementation (no M2 needed for this row).

## 3. Setup

### 3.1 Defense parameters

- M2 gating: disabled with `tau=-1.0`, so every SPU is eligible for purification.
- Score-net checkpoint: `checkpoints/kitti/asap_score_net_trackA_v1.pth`.
- Score anchor blend: `0.75`.
- Completed proxy: `FIXED_RADIUS=0.40`, `INNER_BETA=0.67`, `STRIDE=0.40`.
- Completed LiDAR-SPD-style proxy: `FIXED_RADIUS=0.15`, `INNER_BETA=0.6667`, `STRIDE=0.15`.

## 4. Procedure

1. Reuse the ASAP M1 implementation to enumerate SPUs.
2. Skip M2; pass every SPU straight to M3.
3. Aggregate purified inner points back into a per-frame LiDAR scan.
4. Evaluate the victim detector on the purified val set.
5. Record AP / ASR + average purification time per frame for `E6.1`.

## 5. Expected output

- Purified LiDAR bins.
- AP / ASR per cell.
- Per-frame purification time (used as baseline in `E6.1`).

## 7. Analysis

Both fixed all-unit proxies support ASAP's selectivity claim: all-unit fixed spherical diffusion is heavier and weaker than Track A. The `r=0.15` proxy is more directly tied to LiDAR-SPD's reported radius, and it still trails ASAP under the same attack, data split, score-net checkpoint, and OpenPCDet evaluation protocol. The added PV-RCNN evaluation strengthens the conclusion because the proxy remains below no defense and far below ASAP on a second detector family.

## 8. Issues encountered & resolutions

- `r=0.40` was useful as an internal stress test but is not the radius reported by LiDAR-SPD.
- LiDAR-SPD reports `r1=0.15m, r2=0.10m`; we therefore ran a second proxy with `FIXED_RADIUS=0.15`, `INNER_BETA=0.6667`.

## 9. Next actions

- Add the `r=0.15` row as the main SOTA-style proxy result in the manuscript draft.
- Keep the table/caption wording explicit that this is a LiDAR-SPD-style fixed-radius proxy, not an official reproduction.
- Continue screening 2025/2026 methods, but only run same-protocol experiments when the method can produce full-scene KITTI/nuScenes purified point clouds without changing the victim detector. With the current evidence, the next experimental priority should shift back to strengthening ASAP itself rather than adapting classification-only purifiers.
