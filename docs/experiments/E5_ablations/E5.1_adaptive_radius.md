## 1. Purpose / hypothesis

Replace the density-adaptive radius rule of Equation (M1.1) with a single global radius $r_1 \in \{0.10, 0.20, 0.30, 0.40\}$ m, keeping M2 and M3 unchanged. The initial expected message was that no single fixed radius would match the adaptive rule.

The completed result does **not** support that strong claim on KITTI Perturbation. Fixed `r=0.40` slightly exceeds the adaptive Track A detector mAP while editing more points. This ablation is therefore used as a corrective diagnostic: M1 adaptive radius is a conservative locality prior, not a standalone source of peak AP on this row.

## 7. Analysis

This ablation rejects the original "adaptive beats every fixed radius" hypothesis on KITTI Perturbation. The best fixed radius, `r=0.40`, reaches 61.06 / 34.92, which is slightly above the adaptive Track A reference 61.04 / 34.69. Smaller fixed radii under-edit the scan and remain near the no-defense lower bound.

The useful interpretation is a precision/conservatism tradeoff. Fixed `r=0.40` obtains the best detector metric but edits 27.07% of points, while adaptive Track A edits 21.93% and achieves nearly the same detector performance. M1 should therefore be framed as a locality-preserving adaptive unit construction that avoids a manually chosen global radius and keeps edits more conservative, not as an absolute AP-dominating component in isolation.

For the paper, this row should be included only if space allows and written as a negative/diagnostic ablation. The stronger innovation evidence remains M2 selection vs all-unit diffusion and the detector-agnostic nuScenes pfilter transfer.

## 8. Issues encountered & resolutions

- The original E5.1 hypothesis was too strong. The result forced a claim correction: adaptive M1 is not strictly better than fixed `r=0.40` on KITTI Perturbation.
- The fixed-radius runner uses `SPU_ALPHA=0.0` with `SPU_R_MIN=SPU_R_MAX=R`; since clipping is fixed, every SPU uses the requested radius.

## 9. Next actions

- Keep this as a conservative ablation paragraph, not a headline table claim.
- Next acceptance-critical experiment should focus on main-row improvement or external-baseline credibility, not more M1 radius variants.
