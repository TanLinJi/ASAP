## 1. Purpose / hypothesis

This ablation tests whether the four M2 geometric features are complementary, or whether a simpler one-feature score is enough. The initial diagnostic evaluates feature subsets on the calibration SPU set; the second stage runs full detector validation only for decision-critical variants.

The key paper risk is that if `f_d` alone matches the full M2 detector result, the paper should not overstate four-feature complementarity. If removing `f_d` damages detector mAP, the paper can still argue that density-ratio is the dominant perturbation cue and that the remaining features improve cross-attack coverage.

1. Re-extracted calibration SPU features for KITTI Injection, Perturbation, and Dropping.
2. Refit logistic scorer variants for full, single-feature, and leave-one-out feature sets.
3. Computed AUC, Youden-J, TPR, FPR, and selected threshold for each feature set.
4. Exported `only_f_d` and `drop_f_d` perturbation scorer JSONs.
5. Ran full KITTI E2.2 Perturbation purification and PointPillars eval for the two selected variants in tmux.

## 7. Analysis

The lightweight diagnostic changes the paper risk profile. The original hypothesis, "no single feature is sufficient," is not supported on the perturbation calibration set: `only_f_d` nearly matches full M2 and slightly exceeds full M2 in Youden-J. Removing `f_d` clearly damages perturbation separability, dropping AUC from 0.7610 to 0.6527.

The detector-level validation further weakens any claim that all four features are necessary for KITTI Perturbation. `only_f_d` reaches 61.50 / 34.61, almost identical to the full Track A reference 61.04 / 34.69. `drop_f_d` reaches 61.01 / 34.28, lower but not collapsed. This means that AUC-level separability does not translate one-to-one into detector mAP, and the four-feature M2 should be framed as a cross-attack analytic gate rather than as a perturbation-specific necessity.

The safer paper claim is therefore:

> M2 combines complementary geometric cues across attack families, but the density-ratio cue is the dominant perturbation indicator in the current KITTI calibration set.

This result is useful but not strong enough to become a headline innovation claim. It should be used as a negative/diagnostic ablation that improves the paper's honesty: ASAP's main novelty is the anomaly-selective structure-preservation framework and attack-aware policy, not a claim that every M2 feature is indispensable on every attack family.

## 8. Issues encountered & resolutions

- Lightweight feature extraction for Dropping was slower than Injection/Perturbation because it requires attacked-cloud radius queries around clean SPUs to identify density loss. It completed successfully.
- The original dual-GPU score-net runner only accepted default per-attack scorer JSONs. Added `SCORER_JSON` override to `scripts/run_asap_vpsde_score_net_dual_gpu.sh`.

## 9. Next actions

1. Treat E5.2 as complete for KITTI PointPillars Perturbation.
2. Keep the M2 paper claim conservative: cross-attack analytic gate; `f_d` dominant for perturbation.
3. Prioritize the next experiment toward a stronger acceptance gap: either M1 radius ablation (E5.1) or a stronger main-row improvement on nuScenes/KITTI rather than more M2 feature variants.
