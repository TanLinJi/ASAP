## 1. Purpose / hypothesis

Direct head-to-head: **full ASAP (M1+M2+M3) vs uniform SPU diffusion (M1+M3, no M2 gating)** from `E3.3`. The expected message: **M2 gating is what preserves benign geometry**, since uniform diffusion runs M3 on every SPU and therefore inevitably blurs clean structure.

Null outcome: uniform diffusion and full ASAP tie on both detection metric and ASR — in which case M2 only saves cost and the framing in the paper should be adjusted.

## 2. Dependencies

- `E3.3` (uniform SPU diffusion column).
- `E4.1` (full ASAP column).

## 3. Setup

### 3.1 Configuration

- Dataset: KITTI val.
- Detector: PointPillars.
- Attacks: all three E2 attacks for context.
- This ablation reuses results from `E3.3` and `E4.1`; no extra runs are strictly required, but recompute is allowed if either upstream result was re-run.

### 3.2 Reproducible command

Re-derive from `E3.3` and `E4.1` outputs:

```bash
python scripts/diff_runs.py \
    outputs/main_results/kitti_pointpillars/E4.1/<attack>/asap/result.pkl \
    outputs/defenses/kitti_pointpillars/<attack>/E3.3_uniform/result.pkl
```

## 4. Procedure

1. Pull the per-cell `(AP, ASR)` values for both `E3.3` and `E4.1` ASAP columns.
2. Compute the gap per attack family.
3. Compare against the *clean* baseline from `E1.1` to identify how much each variant hurts clean accuracy when applied to a clean (un-attacked) scan.
