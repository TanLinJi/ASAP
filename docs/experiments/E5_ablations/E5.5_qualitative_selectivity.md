## 1. Purpose / hypothesis

This experiment produces qualitative and per-frame selectivity evidence for the current ASAP story. The hypothesis is that ASAP edits only a minority of points on representative perturbation rows, while nonselective variants edit most points and pfilter removes unsupported artifacts in a disclosed post-processing step.

The paper-facing question is: can we show, visually and quantitatively, that M2/pfilter operate locally rather than hiding a global scan deletion?

## 4. Procedure

1. Rank frames by edit ratio or drop ratio using existing `meta.jsonl` files.
2. Select representative high-impact frames from KITTI Perturbation and nuScenes Perturbation pfilter.
3. For each selected frame, load attacked and purified point clouds.
4. Generate BEV comparison panels and per-frame CSV/Markdown summaries.

## 7. Analysis

The KITTI perturbation cases show a coordinate-editing behavior: the selected high-edit frames edit about 37--38% of points but drop no points. This supports the Track A interpretation that KITTI Perturbation is handled mainly by local score-net coordinate purification.

The nuScenes pfilter cases show the opposite boundary: only about 16--17% of SPUs are flagged and about 4% of points are coordinate-edited, but the support filter drops about 30% of points in these high-drop representative frames. This is useful evidence, but it must be described honestly. ASAP-pfilter is a score-net + support-filter cascade; its nuScenes Perturbation gains should not be attributed to score-net diffusion alone.

These figures are qualitative diagnostics rather than detector metrics. They are best used as an optional paper figure or supplementary figure to make the selectivity and pfilter behavior visually transparent.
