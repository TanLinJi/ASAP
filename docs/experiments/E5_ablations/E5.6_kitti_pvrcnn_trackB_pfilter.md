# E5.6 — Track B diagnostics · KITTI val · PV-RCNN Perturbation

## 1. Purpose

Test low-cost Track B variants for the hardest KITTI row, PV-RCNN under E2.2 Perturbation.

The first hypothesis was that PV-RCNN's low E2.2 recovery might come from sparse unsupported coordinate artifacts, so applying the same support filter after Track A score-net denoising could improve the current Track A result. After that failed, the second hypothesis was that PV-RCNN might need stronger score-net coordinate correction, so we reduced the local-anchor blend from `0.75` to `0.50` without deleting points. After both variants failed, the third test kept the stabilizing `0.75` anchor and only increased VP-SDE truncation from `t_star=0.05` to `0.08`. A fourth test checked whether pushing the same knob to `t_star=0.10` gives a stable cross-detector gain.

## 2. Linked paper section

`paper/04_experiments.md` limitation and ablation discussion only. These rows are not main-table candidates unless a later Track B variant improves over Track A.

## 3. Setup

- Dataset: KITTI val, 3769 frames.
- Detector: PV-RCNN, checkpoint `checkpoints/kitti/pv_rcnn_8369.pth`.
- Attack: E2.2 Perturbation, `outputs/attacks/kitti/E2.2_perturbation/velodyne_attacked`.
- Base purifier: Track A score-net checkpoint `checkpoints/kitti/asap_score_net_trackA_v1.pth`.
- Variant 1, `pfilter_r04_m5`: enable post score-net support filter for `perturbation`; radius `0.4 m`, minimum neighbors `5`, matching the ROR/pfilter rule used elsewhere.
- Variant 2, `blend050`: disable support filtering and set `score_anchor_blend=0.50`.
- Variant 3, `tstar008`: disable support filtering, keep `score_anchor_blend=0.75`, and set `t_star=0.08`.
- Variant 4, `tstar010`: same as `tstar008`, but set `t_star=0.10`.

## 8. Analysis

The KITTI/PV-RCNN pfilter diagnostic is negative. Unlike nuScenes Perturbation, where the support cascade beats ROR on two detectors, KITTI/PV-RCNN E2.2 does not benefit from the same `0.4 m / 5 neighbors` support filter. Car AP drops slightly from Track A's **10.96** to **10.53**, while cross-class mAP drops more clearly from **5.98** to **4.99**.

The likely failure mode is over-removal of sparse but detector-useful evidence. The filter removes an additional **5.32%** of all input points after already editing **21.93%**, and the largest damage appears in Pedestrian/Cyclist, where PV-RCNN is already near floor under this attack.

The blend050 diagnostic is also negative. Reducing `score_anchor_blend` from `0.75` to `0.50` keeps point count fixed, but lowers Car AP from **10.96** to **8.31** and keeps mAP below Track A. This means the PV-RCNN row does not simply need a freer score-net correction; the local-mean anchor is stabilizing rather than over-constraining the current score-net.

The tstar008 diagnostic is positive. Keeping `score_anchor_blend=0.75` and increasing `t_star` from `0.05` to `0.08` improves PV-RCNN E2.2 from **10.96 / 5.98** to **11.23 / 6.26**. The same purified scans also improve PointPillars E2.2 from **61.04 / 34.69** to **61.26 / 34.76**, so the gain is not a detector-specific regression tradeoff.

The tstar010 follow-up is not a stable improvement over tstar008. It increases PV-RCNN Car AP from **11.23** to **11.36**, but lowers PV-RCNN moderate mAP from **6.26** to **6.16** and reduces PointPillars Car AP from **61.26** to **61.06**. Because the paper claim is detector-agnostic robustness and cross-class recovery, the single PV-RCNN Car gain is not enough to replace tstar008.

## 9. Decision

Do not promote KITTI pfilter or blend050 as Track B solutions. Keep `ASAP-pfilter` as a nuScenes-specific disclosed cascade unless a later KITTI variant improves over Track A.

Promote `tstar008` as the current low-cost KITTI E2.2 Track B candidate. The improvement is small, so the paper should describe it as a calibrated inference-time setting rather than a new module. Do not promote `tstar010`; it is logged as a closed micro-sweep point.

Next step:

1. Keep the paper-facing KITTI Perturbation rows on `tstar008`.
2. Stop the `t_star` micro-sweep unless a new objective is introduced; larger `t_star` mainly trades class balance for a tiny PV-RCNN Car gain.
3. Treat PV-RCNN Perturbation as still weak in absolute terms despite the small improvement.
