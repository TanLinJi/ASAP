## 1. Purpose / hypothesis

Per attack family, report **the fraction of candidate SPUs that actually trigger M3**, i.e. $|C^\star|/|C|$ in the notation of Algorithm 1 in `paper/03_method.md`. The expected message: the ratio is **substantially below 1** for benign-dominated scans, which is the geometric reason ASAP's purification cost scales below uniform SPU diffusion.

## 2. Dependencies

- ASAP runs from `E4.1` (per-frame purification metadata).
- Clean baseline runs (for the no-attack ratio).

## 3. Setup

### 3.1 Configuration

- Dataset: KITTI val.
- Detector: PointPillars.
- Use the same M1/M2 hyperparameters as in `E4.1` ASAP rows.

### 3.2 Reproducible command

```bash
python scripts/analyze_cost_metrics.py --out-dir outputs/cost/E6_summary
```

## 4. Procedure

1. Read each frame's purification metadata (number of candidate SPUs $|C|$ and number of accepted SPUs $|C^\star|$).
2. Aggregate per attack family and per scan (mean, std, percentiles).
3. Also report the ratio on the **clean** val split (no attack) as a reference.

## 7. Analysis

The current ASAP policies are selective rather than whole-scene diffusion: on the final nuScenes Perturbation pfilter row, only **22.75%** of candidate SPUs pass the M2 threshold and **18.87%** of SPUs enter the score-net path. The support filter then removes **16.63%** of points, which explains the pfilter gain over ASAP-v1 and must be disclosed as a score-net + support-filter cascade.

The KITTI Dropping score-net row is diagnostic only. The final paper policy skips M3 for Dropping because editing/removal compounds the attack's evidence loss.
