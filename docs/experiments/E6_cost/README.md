# E6 — Cost

Wall-clock and selectivity measurements that back the *Inference cost* discussion in `paper/04_experiments.md` §4.5 (Table 3).

| ID | Measurement | File | Status |
|----|-------------|------|--------|
| E6.1 | Per-frame inference latency (ms) for ASAP policies | [`E6.1_inference_latency.md`](E6.1_inference_latency.md) | **partial, log-derived** |
| E6.2 | Selective ratio $\lvert C^\star\rvert / \lvert C\rvert$ vs attack family | [`E6.2_spu_selection_ratio.md`](E6.2_spu_selection_ratio.md) | **done for current Track A / pfilter outputs** |

Constraints:
- Both E6 experiments must run on **the same machine that produced E4.1** so that latency numbers are directly comparable across defenses.
- Latency is averaged over **at least 500 KITTI val frames**; warm-up runs are discarded.
- E6.2 reports `selective ratio = |selected SPUs after M2 gating| / |candidate SPUs from M1|` per attack family; this number is what makes ASAP's purification cost scale below uniform diffusion.
- Current summary artifacts: `outputs/cost/E6_summary/cost_selective_summary.{csv,json,md}` generated by `scripts/analyze_cost_metrics.py`.
