# 5. Conclusion

We presented **ASAP**, an Adaptive Spherical Anomaly-Guided Purification framework that defends LiDAR-based 3D object detectors against adversarial point-cloud attacks without retraining any detector. ASAP combines density-adaptive Spherical Purification Units (**M1**), a lightweight geometric anomaly scorer (**M2**), and selective score-based purification with an optional support filter for sparse artifacts (**M3**). Experiments across KITTI and nuScenes show that the ASAP family transfers across four detector families, with near-ROR Injection recovery and slightly above-ROR nuScenes Perturbation recovery when the disclosed pfilter cascade is enabled. The main limitation is that Dropping attacks that already remove object evidence should not be described as restored by purification; under the current keyframe-only nuScenes protocol they remain outside the main robustness claim. Future work includes adaptive attacks aware of ASAP's gating, density-drop-specific point reconstruction, and extension to multi-modal LiDAR-camera detectors.
