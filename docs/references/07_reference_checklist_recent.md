## 下载后存放

放入 `/root/autodl-tmp/ASAP/docs/references/`，建议命名:
```
Author_Year_ShortTitle.pdf
```

例如:
- `Tu_2023_Comprehensive_Robustness_IJCV.pdf`
- `Chen_2023_VoxelNeXt_CVPR.pdf`
- `AAAI2025_New_Adversarial_Perspective.pdf`
- `PCLD_2024_Layerwise_Diffusion.pdf`
- `ScAR_2024_Scaling_Robustness.pdf`
